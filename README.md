## About

Chat Viewer gives you a simple, user-friendly way to open exported WhatsApp chats and read the conversation in a clean, familiar layout.

## Features

- WhatsApp-like chat layout
- Import and view exported chat files
- Optional Google Drive-based storage and sharing for user accounts

## Getting Started

### Prerequisites

- Node.js
- npm

### Run locally

```bash
git clone https://github.com/srilakshmikanthanp/chatviewer.git
cd chatviewer
npm install
npx nx serve chatviewer-api
npx nx serve chatviewer-web
```

Then open the web app in your browser.
